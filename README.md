# Design Michang FLEX — Image Edition

아이보리·샴페인 골드 콘셉트의 이미지 중심 홈페이지 최신본입니다.

## 업로드

1. 이 폴더 안의 모든 파일과 `images` 폴더를 GitHub 저장소 최상위에 업로드합니다.
2. 기존 파일이 있다면 같은 이름으로 교체합니다.
3. GitHub와 연결된 Netlify가 자동으로 다시 배포하는지 확인합니다.
4. 공개 주소에서 PC와 모바일 화면을 확인합니다.

## 중요

- `images` 폴더를 빠뜨리면 홈페이지 이미지가 보이지 않습니다.
- 상담 이메일은 실제 주소로 교체해야 합니다.
- 생성 이미지는 추후 디자인미창의 실제 프로젝트 사진으로 교체할 수 있습니다.
